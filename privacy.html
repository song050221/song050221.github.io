개인정보처리방침

쇼츠 업로드 도구 · 시행일 2026년 10월 5일

1. 요청하는 권한

이 도구는 Google 계정 로그인 시 다음 권한 하나만 요청합니다.

  • https://www.googleapis.com/auth/youtube.upload — 로그인한 계정의 YouTube 채널에 동영상을 업로드

채널의 기존 동영상, 댓글, 구독자, 시청 기록, 이메일 주소 등 다른 정보는 읽지 않습니다.

2. 사용 목적

받은 권한은 운영자가 직접 만든 영상 파일과 제목·설명·태그·공개 예약 시각을 운영자 본인의 채널에 업로드하는 데에만 사용합니다.

3. 보관

로그인 후 발급되는 인증 토큰은 운영자 컴퓨터의 로컬 파일에만 저장되며, 별도 서버로 전송하거나 외부에 보관하지 않습니다. 업로드 결과(동영상 ID 등)도 운영자 컴퓨터에만 기록됩니다.

4. 제3자 제공

Google 사용자 데이터를 판매하거나 제3자에게 제공·공유하지 않으며, 광고나 다른 목적에 사용하지 않습니다. 이 도구의 Google API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 권한 철회와 삭제

Google 계정 → 타사 액세스에서 언제든 이 도구의 접근 권한을 철회할 수 있습니다. 철회하면 로컬에 저장된 토큰은 더 이상 쓸 수 없으며, 요청 시 즉시 삭제합니다. 업로드에는 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.
